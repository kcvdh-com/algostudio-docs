# AlgoStudio Teacher Docs

Welcome! This is the guide for teachers using AlgoStudio.

Here you'll learn how to set up problems, write test cases, and check what your students are doing.

---

## What you can do right now

- Create problems with test cases, descriptions, and starter code
- Edit problem files through the browser
- See every submission a student has made, including what changed between attempts

## What's coming

- Creating courses through the UI
- Assigning problems to courses through the UI
- Student enrollment and management
