# Courses

Courses are groups of problems. You can use them to organise problems by topic, week, or class.

!!! warning "Course management through the UI is coming soon"
    Courses currently have to be created directly in the database. The UI for creating and managing courses isn't built yet.

    Once it's ready, you'll be able to:

    - Create a course with a name and icon
    - Add problems to a course
    - Share a course link with students
