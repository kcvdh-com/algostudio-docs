# Getting Started

## Log in

Go to your AlgoStudio URL and click **Log in with GitHub**. You need a GitHub account. If you don't have one, make one at [github.com](https://github.com) — it's free.

## Find a problem

Once you're logged in, go to `/p/<problem-id>` to open a problem. The ID comes from whoever set up the server.

!!! note "Creating problems through the UI is coming soon"
    Right now, problems have to be created directly in the database. Once the UI is ready, you'll be able to create them from the browser.

## Edit a problem

If you have access, go to `/p/<problem-id>/manage` to manage a problem's files. From there you can:

- Edit the description
- Edit the test cases
- Edit the starter code
- Add or remove files

See the [Problems section](problems/index.md) to learn what each file does.
